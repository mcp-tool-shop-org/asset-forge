# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-03-25

### Added

- README.md with project overview, crate table, and quick start
- SECURITY.md with scope and vulnerability reporting
- CHANGELOG.md
- CI workflow (cargo check, test, clippy)
- Complete procedural ship generation pipeline (hull, deck, rails, rig, sails, superstructure)
- 6 ship archetypes with material colors
- GLB export with named mesh groups
- Schema migration (v1 → v2)
- 123 tests across 4 crates
